# Technical Manifest: Manifold Composer Architecture

## 1. B-Spline Surface Manifolds
Every geometric generator is a 2D surface $S(u, v)$ parameterized by $(u, v) \in [0, 1]^2$. 
The surface is generated by a KAN with topology $(2, 32, 32, 3+K)$, where the output layer is a **Tensor Product B-Spline Layer**.

### **Mathematical Hardening: Clamped Knots**
We use **multiplicity 4** knots at the boundaries $\{0, 0, 0, 0, \dots, 1, 1, 1, 1\}$. 
*   **Result:** The B-spline surface becomes interpolatory at the edges.
*   **Significance:** The value at $v=0$ is controlled *only* by the first row of coefficients, enabling bit-perfect pinning.

## 2. Coefficient Welding
Unlike traditional pinning which uses evaluated points, Manifold Composer uses **Direct Coefficient Propagation**.
1.  **Parent Export:** The Parent manifold exports the raw floating-point coefficients of its output socket (e.g., its top row).
2.  **Child Import:** The Child manifold overwrites its own input socket coefficients with the Parent's data.
3.  **Bit-Perfection:** This bypasses all interpolation floating-point drift, ensuring the manifolds are mathematically identical at the seam.

## 3. Topology & Periodicity
The engine is topology-aware. 
*   **`periodic_u` (Tubes):** The Zig kernel applies **Modulo UV Wrapping** and synchronizes the first and last columns of coefficients.
*   **Result:** Seamless closure for cylindrical/tubular objects with zero visual "cracks."

## 4. Silicon-Consistent Memory Layout
To saturate the **AVX-512** registers on Zen 5 hardware, the data pipeline uses an **AoS (Array of Structures)** interleaved layout: `[u, v, x, y, z, c1, c2, c3]`.
*   **Trainer Parity:** This layout is bit-identical to the highly optimized core kernels on the `main` branch.
*   **Zero-Copy:** Dataloaders use `mmap` to stream these samples directly from disk to the Silicon gates.

## 5. Geometric Transformation Chain
*   **Local Space:** Generators evaluate in their normalized [0, 1] unit space.
*   **World Space:** The **Composer** maintains a recursive transformation graph.
*   **Execution:** Vertices are evaluated locally and then transformed via **Column-Major World Matrices** before being meshed.
